Farmer-confirmed: the hopper takes exactly 6 bales. Weight = which stack he loaded from: 3×4s → ~8,100 lb, 4×4s → ~10,200 lb. Load size is no longer a guess.

"Correct count" button + weekly PTZ photos of each stack. Drift never accumulates.
